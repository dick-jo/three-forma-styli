Introduce the v0.5 design-system grammar and consumer contract: named Alpha
scales, typed color groups, strict project-owned runtime-theme policy, fixed
semantic typography ranges and categorical variants, unified composite
terminology for Motion/Typography/Shadow, compact generated token and typography
entrypoints, and a canonical Founder Board and migration path.

Generated workspace packages now expose framework-neutral, dependency-free ESM
contracts for token identities, CSS-variable references, color-ramp binding,
typography selection, native color modes, and runtime theme compilation while
keeping detailed evidence in the manifest and Workbench.
