# Maintained authoring-shape fixtures

These projects are copied into the isolated packed-package test environment and
built through the public CLI. They intentionally avoid the stock preset and
Scatter vocabulary:

- `minimal` proves a small token-only system remains first-class.
- `editorial` proves arbitrary semantic typography roles and external font
  ownership without project font preparation.
- `display` proves a large-format size mode, explicit role calibration,
  multi-layer shadows, and semantic motion can coexist.

Keep each fixture concise enough to audit as authored input. They are product
boundary tests, not galleries or alternative presets.
